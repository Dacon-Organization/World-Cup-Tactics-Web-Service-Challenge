# 12. 실격은 설계로 막는다

저작권·라이선스 위반은 실격 또는 감점이고, 비하 콘텐츠는 심사 제외다. 이 절은 심사자가
당연히 물을 질문 — *"선수 실명을 써도 되나요?"* — 에 대한 선제 답변이며, 방어가
아니라 설계의 일부로 적는다.

## 선수 표기 — 법리가 그은 선을 따라간다

국내 법원은 성명을 **변형해도 특정인이 연상되면** 퍼블리시티권 침해로 판단한 사례가
있다(서울서부지법 2010카합245, 원문 확인 — P7). 게임 업계에서 흔한 "연상되게 살짝
바꾼 이름" 관행은 이 법리와 저촉될 소지가 있어 참고하지 않았다.

그래서 사용자에게 노출되는 모든 표면 — UI, 공유 이미지, 클라이언트 JSON, 그리고
이 기획서까지 — 에서 실명·이니셜·연상형 변형명을 전부 배제하고 **음운 규칙으로
만든 완전 창작 가공명**만 쓴다(P7). 가공명 배정은 무작위다. 역추적 가능한 변환
규칙을 두는 것 자체를 금지했는데, 규칙이 있으면 그 규칙이 곧 "연상"의 통로가 되기
때문이다. 빌드 시점 검증 스크립트가 실명·유사명을 기계적으로 검사한다.

이 방침은 주최 측의 "더미 데이터 직접 구성 권장" 안내와도 맞고, 8절의 학습층
실데이터와는 스키마 수준에서 경계가 유지된다.

## 대회 상징 — 쓰지 않는 편을 택한다

엠블럼·워드마크·트로피·마스코트·공식 서체를 일절 쓰지 않는다. 특히 **대회명의 영문
워드마크는 단독 표기까지 등록 상표**이므로(P7), 그 표기를 서비스명·로고·그래픽은
물론 이 문서 본문에서도 쓰지 않는다. 한국어로 대회를 서술적으로 언급하는 최소한의
경우에만 지칭하고, 그때마다 비공식 프로젝트임을 함께 밝힌다.

대체 전략의 근거는 권리자 측 가이드라인 자체에 있다. 해당 가이드라인은 비권리자에게
"generic football or country-related images and/or terminology"를 쓰라고 권한다
(§5, 원문 p12 — P7). 그래서 이 서비스의 시각 자산은 **국기 아이콘 + 팀 대표색 팔레트
+ 자체 제작 SVG(피치·전술 기호)** 로만 구성한다. 같은 가이드라인 §7이 "선수 등
제3자의 권리는 별도"라고 명시하므로(P7), 위의 가공명 원칙이 상징 배제와 **별개로**
필요하다는 점도 원문으로 뒷받침된다.

## 에셋마다 출처와 라이선스가 있다

| 에셋 | 출처 | 라이선스 (원문 확인 — P7) | 우리가 지는 의무 |
|:----------------------|:-------------------------|:-----------------------|:----------------------------------|
| 웹폰트 | Pretendard | SIL OFL 1.1 | 폰트 파일을 저장소에 둘 경우 LICENSE 동봉 |
| UI 아이콘 | Lucide | ISC (일부 MIT 병기) | 고지 유지 |
| 국기 | flag-icons | MIT | 고지 유지 |
| 피치·전술 기호·카드 그래픽 | 자체 제작 SVG | 자체 저작 | — |
| 학습 데이터 (1차) | jfjelstul/worldcup | CC BY-SA 4.0 | **분리 고지** — 산출물 고지를 코드 라이선스와 별도 문서에 |
| Elo 입력 (2차) | martj42/international_results | CC0 1.0 | 없음 (투명성 위해 자발 고지) |

두 가지 판단을 기록해 둔다. 첫째, 공유용 OG 이미지는 서버에서 렌더된 PNG 산출물이므로
**폰트 파일 재배포에 해당하지 않는다** — OFL상 문제가 없다(P7). 둘째, 코드
라이선스와 데이터셋 라이선스는 반드시 분리해 고지한다. CC BY-SA의 동일조건변경허락
조항이 코드 쪽으로 번지지 않게 하는 경계이기 때문이다(P10).

## 비하 금지는 문장 단위로 관리한다

특정 선수·감독·팀·국가의 판단을 "잘못·실수·패착"으로 규정하는 표현을 전 화면·전
카드·전 문서에서 금지한다. 이것은 정책 선언이 아니라 검수 항목이다 — 조판·배포 전에
카피를 전수 검사한다.

서술의 관점은 하나뿐이다. **"다른 선택지가 있었다."** 이 관점은 제약이 아니라 이
서비스의 전제이기도 하다. 어떤 선택이 틀렸다고 말할 수 있다면 애초에 확률을 계산할
이유가 없다.
