# 기획서 원고 인덱스 v2.0

> 기획서 PDF의 마크다운 원고 정본입니다. **v1.0에서 전면 개작**했습니다 —
> 서비스명 변경(「만약의 감독」 → **RE:FORMATION**), 문체 전면 재작성, 시각자료 신설.
> 조판 입력은 이 폴더의 16개 파일이며, 검수 기록은 원고에서 분리해
> [_검수기록_v2_0.md](_검수기록_v2_0.md)에 둡니다.

## v1.0 대비 변경 요약

| 항목 | v1.0 | v2.0 | 이유 |
|---|---|---|---|
| 서비스명 | 만약의 감독 | **RE:FORMATION (리포메이션)** | `RE:`(재생·재계산·답장) + `FORMATION`(포메이션)이 3기능 축을 한 단어로 담음 |
| 문체 | 절마다 "핵심 메시지 —" 선언 + 불릿 나열 | 주장형 절 제목 + 서술 문단, 반론 선제 대응 | "기획서를 설계한 문서"가 아니라 기획서 자체로 읽히게 |
| 메타 구조 | `> 분량 목표·방어` 머리글, `검수 메모` 절, `[조판: ]` 태그 | 전량 제거 (검수 기록은 별도 파일) | 독자에게 보일 필요가 없는 작업 지시가 본문에 노출돼 있었음 |
| 표지 | "표지 구성" 표로 표지를 **설명** | 실제 표지 이미지 | 위와 같음 |
| 시각자료 | mermaid 6종 + 그래픽 자리 10건 | **mermaid 9종 + 렌더 그림 14종** (자리 0건) | 조사·분석량 대비 시각자료 부족 |
| 데이터 그림 | 노트북 그림 1종 인용 | 분석 실측 재렌더 7종 (재현 스크립트 포함) | 분석 결과가 기획서에 거의 반영돼 있지 않았음 |
| 대회 상징 표기 | 영문 워드마크를 배제 규칙 설명 중 2회 지면 표기 | 지면 표기 0회 — 한국어 서술로 우회 | 실격 리스크 최소화 (사용자 결정 2026-07-26) |

## 조판

```bash
python dev/typeset/make_figures.py && python dev/typeset/build.py
```

- `make_figures.py` — 분석 실측·디자인 자산 14종을 `dev/typeset/figures/`에 렌더
- `build.py` — 16개 절 결합 → mermaid 렌더 → 이미지 경로 정규화 → Pandoc + XeLaTeX → PDF

원고의 이미지 경로는 저장소 상대 경로(`../../../../dev/typeset/figures/...`)라
GitHub에서도 그대로 보이며, 조판 시 `build.py`가 빌드 디렉터리 기준으로 바꿔 씁니다.
