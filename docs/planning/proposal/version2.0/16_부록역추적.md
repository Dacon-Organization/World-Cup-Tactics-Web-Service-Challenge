원문을 저장소에 보존하고 있으므로, 아래 표의 어느 행에서든 원문까지 되짚을 수 있다.

## 그림의 출처

이 문서의 그림 중 다음은 **우리가 직접 돌린 분석의 산출**이며, 생성 스크립트가
저장소에 있다(`dev/typeset/make_figures.py`). 같은 명령으로 언제든 재생성된다.

| 그림 | 데이터 | 재현 방법 |
|:----------------------------|:---------------------------------------------|:--------------------------------|
| Elo 입력 확장 효과 (9절) | 노트북 02장 실측 — 964 vs 49,520경기 | 분석 노트북 02장 재실행 |
| Elo 궤적 (9절) | A매치 49,520경기 · 커밋 핀 고정 | `python dev/typeset/make_figures.py` |
| Elo 차이별 결과 분포 (9절) | 월드컵 본선 964경기 · 사전 레이팅 | 동일 |
| 득점 분포와 기저율 (9절) | 월드컵 본선 964경기 | 동일 |
| 몬테카를로 표본오차 (7절) | 산식 유도 (데이터 불요) | 동일 |
| RPS 방어선 (9절) | P12 수집 수치 | 동일 |
| 세 경기 지표 (2절) | P6 · P11 · P13 확정값 | 동일 |

나머지 그림(표지 키 비주얼, 와이어프레임, 확률 표기, 공유 카드, 진출선 도해)은 설계
의도를 그린 것으로, 실제 화면이 아니라 **설계안**이다. 구현 결과가 이와 다르면
저장소 README에 차이를 적는다(14절).
